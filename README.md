## 📋 Descripción del Proyecto
Este repositorio contiene la solución técnica desarrollada para el **Examen 3** del curso de **Desarrollo de Aplicaciones en Internet**. El proyecto implementa una arquitectura robusta basada en el framework **Laravel**, enfocada en la gestión eficiente de datos y seguridad en el lado del servidor.

## 🛠 Stack Tecnológico
| Componente | Tecnología |
| :--- | :--- |
| **Framework** | Laravel 10.x |
| **Lenguaje** | PHP 8.2+ |
| **Base de Datos** | MySQL |
| **Frontend** | Blade Templates / Vite |

## 🚀 Características Implementadas
- [x] **Arquitectura MVC:** Separación clara de responsabilidades.
- [x] **Validación Dinámica:** Implementación de reglas de negocio en el servidor.
- [x] **Seguridad:** Protección nativa contra vulnerabilidades (CSRF, XSS, SQLi).
- [x] **Gestión de Datos:** Migraciones y consultas preparadas (Eloquent ORM).
